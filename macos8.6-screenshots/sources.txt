# Notes
# 1. MacRumors attachments (713935, 1745504, 847569) come from thread
#    https://forums.macrumors.com/threads/mac-os-8-6-findings-and-ramblings.2021922/
#    The forum serves a recompressed JPEG rendition: byte size today differs from the copy
#    saved here, but pixel dimensions are identical and `compare -metric RMSE` gives
#    1.6-3.5% normalized error for 713935/1745504 - i.e. the same picture re-encoded, not a
#    different image. 847569 is md5-identical (d2743fc4eaddcb65bb9577967fe0b230).
# 2. desktop_fandom.png was served by Fandom as WebP and re-encoded to PNG with `convert -strip`
#    (identical 2560x1442 geometry). sherlock_fandom.jpg is a WebP payload despite the .jpg
#    extension, exactly as served.
# 3. archive.org stills (000035/000045/000080/000085) are byte-exact matches (md5-verified)
#    against the archive.org .thumbs renditions of item 1998-apple-i-mac-booting-into-mac-os-8.6.
# 4. BetaWiki originals are behind a 403 for live fetches; all BetaWiki files here were pulled
#    through the Wayback Machine image proxy (web.archive.org/web/<timestamp>im_/...).
# 5. BetaWiki filenames can disagree with file contents. Every About/Info asset above was
#    visually transcribed before labelling; none is labelled 8.6 unless the version string is
#    legible in the image itself.
# 6. Rejected and not included: it.wikipedia "Mac OS 8 screenshot.png" (no version string
#    legible -> version-ambiguous) and winmac.emuunlim.com OS8.jpg (mock showing "Mac OS 8.8"
#    on an "Intel Pentium" - not real Mac OS).
