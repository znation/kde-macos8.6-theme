## Planned


### Reference-pixel sampler: exclude known background colors from histograms (planned 2026-11-02 by the plan role) — done 2026-11-02 by the feature role

**Goal.** Inspect bevel and accent palettes without known background colors consuming the `--top-colors` slots. Existing minimum-count and fraction filters suppress rare colors, but cannot remove a named dominant background.

**Approach and files.** In `tools/sample_arguments.py::build_parser`, add repeatable `--exclude-color RRGGBB`, parsed by the existing `rgb_argument`, defaulting to `None`; `option_error` requires `--histogram` before image access. In `tools/sample_report_histogram.py::_histogram_result`, form a set of excluded RGB tuples and filter counted candidates by `color[:3]` before minimum-count/fraction predicates and top-N selection. With `--alpha`, exclude every opacity variant of the named RGB, including stored RGB under zero alpha; no tolerance or alpha selector is added. Preserve full-region counts, fraction denominator and original distinct RGB/RGBA total. Explicit exclusion always enables `total_colors` and `omitted_pixels`, even for an absent color; omitted pixels include exclusion and other filters without double counting. Extend both result assembly and `report_histogram`'s text-total condition. Spatial fields remain limited to emitted keys through `_histogram_spatial_fields`. Add `tests/test_sample_histogram_exclusions.py` using the CLI fixtures patterned on `TestSampleHistogramMinimumCount`, and document semantics in README.md and the sampler histogram section of `docs/invariants.md`. This is one selection feature; no theme artwork changes.

**Acceptance criteria.** Pin text/JSON output for an offset crop with a dominant excluded background, remaining count ties and `--top-colors`; prove exclusion precedes truncation. Cover repeated exclusions, duplicates, lowercase and optional `#`, absent colors, and exclusion of the entire palette (empty colors, full area omitted). Combine with minimum count/fraction, fractions and spatial fields, verifying retained values use full-region occurrences and denominator. RGBA fixtures distinguish original opacity-key totals while excluding every matching RGB variant; include opaque fallback and transparent stored RGB. Missing/malformed color arguments and use without histogram (ordinary, runs and find-color modes) exit 2 with empty stdout before header or image decoding reads. Verify omitted-option output retains existing fixtures, help/default parsing, and package/direct-script parity. Run `make check` after final edits.

### Reference-pixel sampler: page through matching coordinates (planned 2026-11-02 by the plan role) — done 2026-11-02 by the feature role

**Goal.** Inspect later color matches without increasing the bounded coordinate list or manually changing the crop. The existing `--match-pixels` retains a row-major prefix; provide an offset into that same match sequence, independently of the waiting histogram-exclusion plan.

**Approach and files.** In `tools/sample_arguments.py::build_parser`, add `--match-pixel-offset N` with default `None`; parse a nonnegative plain ASCII integer using `plain_number` and a small local validator. `option_error` requires `--match-pixels` when the offset is explicitly supplied, including zero; the existing coordinate-limit validation still requires `--find-color`. In `tools/sample_report_search.py::_search_match`, use the existing full match count to skip the first N matching pixels before retaining up to `args.match_pixels` coordinates. Offset counts predicate matches, not scanned pixels. Keep the existing full traversal for count, bounds and optional spatial diagnostics; store at most the coordinate limit. Preserve `omitted_pixels = count - len(pixels)`, including both skipped and trailing matches. Only explicit offset use adds `match.pixel_offset` in JSON and a `pixel offset: N` text line immediately before `matching pixels:` in `report_search`. An offset at or beyond the match count returns an empty coordinate list. Add `tests/test_sample_match_pixel_offset.py` patterned on `TestSampleMatchPixels`, and document pagination and omitted-count semantics in README.md and the sampler search row of `docs/invariants.md`. No dependency on histogram exclusions or new package is needed.

**Acceptance criteria.** Literal text/JSON fixtures pin pages of an offset, nonsquare crop with nonmatching gaps and matches crossing row boundaries; concatenating successive pages reproduces the full row-major matching sequence without repeats. Cover explicit zero, a partial final page, offset equal to or greater than count, no matches, and one-pixel regions. Exercise tolerance boundaries, exact-alpha rejection, stored RGB beneath alpha zero and opaque fallback. Compare full count, bounds, fraction, centroid and run diagnostics against the same search without pagination. Assert omitted counts include skipped matches, and an out-of-range page omits the full match count. Verify omitted-offset output against existing fixtures, explicit metadata and parser defaults, help and direct-script parity. Reject negative, fractional, exponent, underscore, non-ASCII, whitespace, nonnumeric and missing arguments with status 2 and empty stdout before header or decode reads; reject offset without `--match-pixels` in ordinary, histogram, runs and search modes. Include an integer conversion-limit failure without traceback. Run `make check` after final edits.
