### Reference-pixel sampler: summarize the longest horizontal color-match run (planned 2026-11-02 by the plan role)

**Goal.** Locate an uninterrupted reference border band without emitting the complete `--match-runs` list. The existing `_MatchRuns` collector in `tools/sample_match_runs.py` retains horizontal intervals; `tools/sample_report_search.py::_search_match` exposes lists but no longest-run summary. Related finished horizontal/vertical interval plans cover full lists, not this summary.

**Approach and files.** Add boolean `--longest-match-run` in `tools/sample_arguments.py::build_parser`, requiring `--find-color` through `option_error` before image reads. Extend `_MatchRuns` with an optional summary flag, defaulting false for existing callers, and a `longest_run` attribute. Route both horizontal closing paths through one helper that updates the best run only on a strictly greater length, retaining the earliest row-major start on ties. Enable horizontal tracking when either horizontal option is requested, but append records to `runs` only for `--match-runs`; summary-only collection retains one best record and the current run rather than a complete interval list. Preserve `finish`'s existing pair-of-lists return contract. Wire the flag through `_search_match` and emit `match.longest_run` as an absolute `{x,y,length}` record or `null`; `report_search` prints `longest matching run: X,Y,LENGTH` or `longest matching run: none` after existing diagnostics. Use the existing tolerance/alpha predicate and positioned traversal. This option is horizontal regardless of `--match-column-runs`; it does not enable or change `--run-axis`. Add `tests/test_sample_longest_match_run.py` using `CliTestCase`, document the option in README.md, and append a dated tooling invariant in docs/invariants.md. These six files plus the new test bound one run; no theme values change.

Cover absent matches, full coverage, single pixel, single row and single column. Exercise tolerance-boundary inclusion with unequal neighboring RGB values, exact-alpha rejection, RGB beneath alpha zero, and opaque fallback. Combine with `--match-runs`, `--match-column-runs` and `--match-pixels 1` to prove the summary covers the full region and existing lists retain their meanings. A collector-level test feeding many short runs with summary alone asserts its horizontal list stays empty while the best record is correct. Assert omission without the flag, misuse rejection with status 2 and empty stdout before header/decode access, help and direct-script invocation, one positioned traversal when combined with other diagnostics, and decoding once with `max_rows=y+height`. Run `make check` after final edits.
