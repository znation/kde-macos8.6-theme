### Reference-pixel sampler: page through the bounded scanline run list (planned 2026-11-04 by the plan role)

**Goal and grounding.** Inspect later border or gradient runs without printing the preceding runs. `tools/sample_report_runs.py::_runs_result` supports a global `--max-runs` prefix after color and length filtering, but has no offset. Searches of sampler code, tests, the queue and archive found histogram and match-coordinate offsets, and the finished prefix-cap plan, but no scanline-run pagination. This is independent of the waiting Make render selector.

**Approach and files.** Add optional `--run-offset K` in `tools/sample_arguments.py::build_parser`, parsing a nonnegative ASCII integer with `plain_number` and requiring `--max-runs` in `option_error` (which already requires `--runs`). In `tools/sample_report_runs.py::_runs_result`, skip K eligible completed runs after color inclusion/exclusion and inclusive length filters, then retain at most `max_runs` runs across the complete traversal. Count skipped and trailing eligible runs together in existing `omitted_runs`; continue full-region summaries. Do not retain skipped records or build the full region list to slice it: cross-scanline retained storage stays bounded by the page size, with existing per-scanline allocation unchanged. Explicit offsets add integer `run_offset` to JSON and `run offset: K` before the text run list; omitted offsets preserve current output. Add `tests/test_sample_runs_offset.py` using `TestSampleRunsLimit`'s CLI fixture style, document paging beside `--max-runs` in README.md, and extend the max-runs tooling row in docs/invariants.md. Scope is these five files and at most a few hundred lines including tests; no other report mode changes.

**Acceptance criteria.**
- For rows `AABB` and `ACCC` in a 4x2 RGB region, horizontal runs with limit 2 and offset 1 report B at `(2,0)` length 2 and A at `(0,1)` length 1, with `omitted_runs=2`. Offset 0 reports the existing prefix and adds `run_offset=0`; offset 4 or larger reports an empty list and 4 omitted runs. Text and JSON expose the same page and offset.
- Excluding A on that fixture, limit 1 and offset 1 report C at `(1,1)` length 3 and 1 omitted run. Length filters also precede paging; contradictory cutoffs yield an empty list and zero omitted runs. With run-count, scanline-count and longest-run summaries enabled, the unfiltered values remain 4, `[2,2]`, and C's length-3 segment. A cropped vertical fixture verifies absolute coordinates and one offset across columns; an RGBA fixture verifies opacity-separated runs consume separate slots under `--alpha`.
- Negative, fractional and non-ASCII offsets fail with exit 2 and empty stdout. An offset without `--max-runs` fails before opening a missing image, naming both options. Omitting the offset preserves existing text and JSON fields. Help and README explain that the offset counts eligible runs, while omitted counts include both skipped and trailing runs. Tests must distinguish skipping before filtering from skipping after filtering. `make check` passes after the final edit.
