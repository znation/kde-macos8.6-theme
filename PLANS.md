**Acceptance criteria.**
- Compared 3x4 crops with row masks `101`, `101`, `001`, `101` report JSON `difference_column_run_count=3`, text `difference column run count: 3`, and seven differing pixels. The vertical list contains crop-relative starts (0,0), (0,3), (2,0) with lengths 2,1,4. Focused tests reject full-list collection in count-only mode and an extra counter scan when the vertical list is requested, including an empty list. Combining horizontal count, longest-column summary, length filters and worst-pixel paging preserves their separately expected results. Comparison metrics, verdict and exit status agree with the invocation without the new flag on passing and failing inputs.
