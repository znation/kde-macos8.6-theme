Independent of the waiting `--longest-run` entry: different option blocks in `tools/sample_arguments.py` and a different report module, so either may land first.

**Approach and files.** Add boolean `--row-color-counts` and `--column-color-counts` in `tools/sample_arguments.py::build_parser` beside the other histogram-only options after `--color-centroids`. In `option_error`, add one check per flag next to the other `--histogram`-requirement checks: `--row-color-counts requires --histogram` and `--column-color-counts requires --histogram`, each before the PNG reads. In `tools/sample_report_histogram.py`, extend `_histogram_spatial_fields` to collect, over one `_positioned_region_pixels` traversal on the complete region, a per-row set of colors when `--row-color-counts` is set and a per-column set when `--column-color-counts` is set, grouped exactly like emitted colors: RGB normally, RGBA when `--alpha` is set (RGB merging opacity variants). In `_histogram_result`, expose `row_color_counts` and `column_color_counts` only when requested, each as an array of region-relative scanline results: `args.height` distinct-color counts row by row, or `args.width` distinct-color counts column by column, unaffected by `--top-colors`, `--color-offset`, `--min-color-count`/`--max-color-count`, `--min-color-fraction`/`--max-color-fraction`, `--exclude-color` and `--include-color`, which still only select the displayed page (the same full-region coverage the search mode guarantees for `matching rows`). In `report_histogram`, print `row color counts: [1,2,...]` and `column color counts: [1,2,...]` as the compact JSON arrays, after the color list and before the optional `total colors:` line. Add `tests/test_sample_histogram_row_counts.py::TestSampleHistogramRowCounts` and `tests/test_sample_histogram_column_counts.py::TestSampleHistogramColumnCounts` patterned on `tests/test_sample_histogram_bounds.py::TestSampleHistogramBounds`, extend the rejection table in `tests/test_sample_option_validation.py::TestSampleOptionValidation`, document both options in README.md's histogram section, and add dated tooling rows in docs/invariants.md. A single-row region reports a one-element row array with that row's distinct count and a `column_color_counts` array as long as the region is wide; a 1x1 region reports `[1]` for both. With `--alpha`, two pixels of equal RGB but different alpha in one scanline count as two colors, while without `--alpha` they count as one; transparent pixels follow their RGB bytes as elsewhere in the histogram. Omitting both flags omits both JSON keys, both text lines and the collection pass without altering any existing field, text line or filter result. Select the first `min(K + N, len(counts))` candidates with the existing heap selection and retain slice `[K:K + N]`, where N is the top-colors limit.
