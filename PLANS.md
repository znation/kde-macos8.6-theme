### Reference-pixel sampler: page through ranked histogram colors (planned 2026-11-03 by the plan role)

**Goal.** Inspect later palette entries without increasing the displayed palette or changing the crop. The existing histogram filters and `--top-colors` select a leading page; source and archive searches found coordinate pagination and worst-pixel pagination, but no histogram offset.

**Approach and files.** Add optional `--color-offset K`, default None, in `tools/sample_arguments.py::build_parser`, with a nonnegative plain ASCII integer converter in `tools/sample_validators.py` patterned on `match_pixel_offset`. In `option_error`, immediately after the existing top-colors check, require `--top-colors` for explicit offset use, including zero; the existing top-colors check continues to require histogram mode. In `tools/sample_report_histogram.py::_histogram_result`, apply exclusions and count/fraction filters before ranking by descending count then ascending RGB/RGBA tuple. Select the first `min(K + N, len(counts))` candidates with the existing heap selection and retain slice `[K:K + N]`, where N is the top-colors limit. Preserve original `total_colors` and calculate omitted pixels as region area minus emitted counts, including filtered, skipped and trailing colors. Existing report fields suffice: add no offset metadata. Spatial diagnostics continue to describe emitted colors using their complete region occurrences. Add `tests/test_sample_histogram_offset.py`, extend `tests/test_sample_option_validation.py::TestSampleOptionValidation`, and document pagination and selection storage (offset plus limit, bounded by distinct-color count) in README.md and docs/invariants.md. This is one bounded option across seven files, at most a few hundred changed lines; decoding and theme artwork stay outside its scope.

**Acceptance criteria.** Given an offset eight-pixel crop with RGB counts 3, 2, 2 and 1, `--top-colors 2 --color-offset 1` emits the two count-2 colors in ascending tuple order, with `total_colors=4` and `omitted_pixels=4`; offset 3 emits the count-1 color and omits seven pixels, and offsets 4 and 100 return an empty palette and omit eight. Excluding the count-3 color before offset 1 yields the later count-2 tuple followed by the count-1 tuple; count and fraction cutoffs likewise operate before pagination. Explicit zero matches the existing first-page report, and omitting the option preserves existing output. Fractions retain denominator eight; positions, bounds and centroids remain absolute and cover every occurrence of each emitted color. An RGBA fixture verifies opacity participates in tie order and grouping, including stored RGB under zero alpha, while RGB mode merges opacity variants and opaque input uses alpha 255. Text and JSON agree on selected colors and totals; package and direct-script invocations agree. Negative, fractional, exponent, underscore, whitespace, non-ASCII, nonnumeric and missing offsets exit 2 with empty stdout before PNG reads. Explicit offset without top-colors, including zero in histogram mode, reports `--color-offset requires --top-colors`; top-colors outside histogram retains its existing diagnostic precedence. An integer beyond Python's conversion limit fails without a traceback, while a large valid offset returns an empty page. Run `make check` after final edits.

### Reference-pixel sampler: page through ranked histogram colors (planned 2026-11-03 by the plan role)

**Goal.** Inspect later palette entries without printing the complete histogram. Source/option searches and related finished histogram-limit plans show leading-color limits and filtering, but no histogram offset.

**Approach and files.** Add optional `--color-offset K` (default None) in `tools/sample_arguments.py::build_parser`; `option_error` requires `--top-colors` for explicit use, including zero, after the existing top-colors mode check. Add `color_offset` in `tools/sample_validators.py`, following `match_pixel_offset` with flag-specific diagnostics: nonnegative ASCII decimal integer via `plain_number`. In `tools/sample_report_histogram.py::_histogram_result`, apply existing color filters first, select the first K+N ranked eligible colors with `nsmallest`, then emit entries K through K+N-1, where N is top-colors. Clamp the selection size to the original distinct-color count before selection so a huge valid offset cannot cause allocation proportional to its numeric value. Ranking remains descending count then ascending RGB/RGBA tuple. Existing totals count original distinct colors and region area minus emitted counts, including skipped colors; fractions keep the full region denominator and spatial fields describe emitted colors. Explicit use adds top-level JSON `color_offset` and a `color offset: K` text line immediately before the color records in `report_histogram`. Omitted use preserves the output schema. Add `tests/test_sample_histogram_offset.py` using `CliTestCase`, extend `tests/test_sample_option_validation.py::TestSampleOptionValidation`, and document the option and selection-storage bound in README.md and the histogram row of docs/invariants.md. These seven files form one run; no decoder change or dependency.

**Acceptance criteria.** An offset crop of eight pixels has colors A=(0,0,0), B=(0,1,0), C=(1,0,0), D=(2,0,0) with counts 3,2,2,1. K=1,N=2 emits B,C in that order, `total_colors=4`, `omitted_pixels=4`, and fractions 0.25 each. K=3,N=2 emits D and omits seven pixels; K=4 or a much larger valid K emits no colors and omits eight. Filtering out A before K=1,N=1 emits C and omits six pixels. Successive pages reproduce the eligible ranked palette without repetition; explicit zero matches the ordinary leading page apart from offset metadata. Text and JSON agree, direct-script and package entry points agree, and omission retains existing output fixtures. Cover count/fraction filters, exclusions, empty eligible palettes, RGB/RGBA grouping with opacity ties, stored RGB under zero alpha, opaque fallback, and absolute bounds/positions/centroids of emitted colors. Negative, fractional, exponent, whitespace-padded, underscore, non-ASCII, empty and missing offsets fail with status 2 and empty stdout before PNG reads, including integer conversion-limit failures without traceback. Offset without top-colors fails before reads in histogram, ordinary, runs and search modes, and explicit zero is validated too; existing diagnostic precedence stays intact. Parser default is None and help lists the option. Run `make check` after final edits.
