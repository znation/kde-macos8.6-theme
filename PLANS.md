**Goal.** Locate an uninterrupted reference border band without emitting the complete `--match-runs` list. **Approach and files.** Add boolean `--longest-match-run` in `tools/sample_arguments.py::build_parser`, requiring `--find-color` through `option_error` before image reads. Extend `_MatchRuns` with an optional summary flag, defaulting false for existing callers, and a `longest_run` attribute. Route both horizontal closing paths through one helper that updates the best run only on a strictly greater length, retaining the earliest row-major start on ties. Enable horizontal tracking when either horizontal option is requested, but append records to `runs` only for `--match-runs`; summary-only collection retains one best record and the current run rather than a complete interval list. Preserve `finish`'s existing pair-of-lists return contract. Wire the flag through `_search_match` and emit `match.longest_run` as an absolute `{x,y,length}` record or `null`; `report_search` prints `longest matching run: X,Y,LENGTH` or `longest matching run: none` after existing diagnostics. Use the existing tolerance/alpha predicate and positioned traversal. This option is horizontal regardless of `--match-column-runs`; it does not enable or change `--run-axis`. Add `tests/test_sample_longest_match_run.py` using `CliTestCase`, document the option in README.md, and append a dated tooling invariant in docs/invariants.md. These six files plus the new test bound one run; no theme values change.

**Acceptance criteria.** Offset nonsquare synthetic crops independently pin exact text/JSON results for unequal and tied runs, separated segments, empty rows, right-edge and final-row flushing, and adjacent matching row boundaries that must stay separate. Cover absent matches, full coverage, single pixel, single row and single column. Exercise tolerance-boundary inclusion with unequal neighboring RGB values, exact-alpha rejection, RGB beneath alpha zero, and opaque fallback. Combine with `--match-runs`, `--match-column-runs` and `--match-pixels 1` to prove the summary covers the full region and existing lists retain their meanings. A collector-level test feeding many short runs with summary alone asserts its horizontal list stays empty while the best record is correct. Assert omission without the flag, misuse rejection with status 2 and empty stdout before header/decode access, help and direct-script invocation, one positioned traversal when combined with other diagnostics, and decoding once with `max_rows=y+height`. Run `make check` after final edits.

### Fidelity mismatch bounds: share row and column interval collection (planned 2026-11-02 by the plan role)

**Goal.** Keep the two enclosing-interval diagnostics consistent with less duplicated bookkeeping. `tools/fidelity_spatial.py::difference_row_bounds` and `difference_column_bounds` repeat the same predicate and first/last tracking with swapped axes. Source and archive searches found the public diagnostics and the separate run-collector extraction, but no shared bounds collector. This cleanup is independent of the waiting sampler summary.

**Approach and files.** Extract `_difference_axis_bounds(candidate, reference, tolerance, *, vertical)` in `tools/fidelity_spatial.py`; keep both public functions as wrappers selecting the axis. Choose scanline count/length and output keys once: horizontal uses height/width and `x`/`width`, vertical uses width/height and `y`/`height`. Map each scanline/offset to the existing row-major pixel index, compare with `_absolute_deltas` using strict maximum-channel delta greater than tolerance, and collect first/last offsets. Emit one entry per scanline, `None` for no mismatch or an inclusive enclosing interval, preserving key order and gaps. Retain direct/package imports and avoid a mask, transposed image or run-list intermediary. Extend `tests/test_fidelity_row_bounds.py::TestDifferenceRowBounds` and `tests/test_fidelity_column_bounds.py::TestDifferenceColumnBounds`; these three files bound the change. The row/column bounds guarantees in docs/invariants.md remain the contract; no guarantee, CLI or report-format change is intended.

**Acceptance criteria.** Explicit expected dictionaries for nonsquare fixtures pin each axis, disconnected mismatches, empty scanlines, first/last offsets and inclusive lengths. Cover single pixel, single row, single column, identical images and full mismatch coverage; retain strict tolerance-boundary exclusion, absent alpha as 255, alpha-only differences and RGB beneath zero alpha. Existing CLI cases retain crop-relative JSON/text output, combined row/column reporting, PASS/FAIL behavior, omission without flags, direct-script invocation and usage/read errors. Add a transpose-equivalence test with an explicit expected result as well, so axis mapping cannot pass solely through shared assumptions. Run `make check` after final edits. Keep this a small extraction without combining scans across separately requested diagnostics.
