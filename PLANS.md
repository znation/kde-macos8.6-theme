### Platinum GTK 4 boxed lists: square joined-list corners (planned 2026-10-29 by the plan role; independent of the queued GTK 4 shortcut keycaps)

**Goal.** Square the joined boxed-list container and its end-row paint, including expanded and collapsed end rows. Treat this as one corner adaptation; container and child corners must agree.

**Grounding.** Searches of `theme/gtk`, `tests/test_gtk4_theme.py`, `PLANS.md` and `PLANS-DONE.md` found no `boxed-list` or `list.content` rules or plan for them. The completed card plan explicitly excludes boxed lists. In `/usr/lib/x86_64-linux-gnu/libadwaita-1.so.0`, resource `/org/gnome/Adwaita/styles/base.css`, the Cards group gives `list.boxed-list` and `list.content` a 12px radius, while the Boxed Lists group rounds their first/last rows, expander headers and expanded nested-list bottoms. No reference screenshot shows a GTK boxed list. Reuse the sheet's `frame > border, .frame` zero radius as a documented platform adaptation, not a sampled boxed-list metric. The existing `make apply-gtk` user stylesheet import supplies the library override path.

**Approach and files.** Beside the frame treatment in `theme/gtk/org.macos8.desktop/gtk-4.0/gtk.css`, add one rule with exactly `border-radius: 0`. Its selectors are each of `list.boxed-list` and `list.content` combined with each of these suffixes: the empty suffix, ` > row:first-child`, ` > row:last-child`, ` > row:first-child.expander row.header`, ` > row:last-child.expander:not(:checked)`, ` > row:last-child.expander:not(:checked) row.header`, ` > row:last-child.expander:checked list.nested`, and ` > row:last-child.expander:checked list.nested > row:last-child`. This symmetric mapping covers the stock corner longhands without copying stock border-width declarations. Add a dated provenance comment naming the missing reference surface and frame source; keep the literal library name out of CSS comments because `test_stands_alone` rejects the substring `adwaita`. Add `TestGtk4Theme.test_boxed_list_corners` in `tests/test_gtk4_theme.py`, following `test_card_corners`, and a dated provenance row under `## gtk` in `docs/invariants.md` naming the library resource, adaptation, import scope and test. Exclude `list.boxed-list-separate`, generic rows, card/keycap rules, colors, borders, shadows, spacing and focus styling.

**Acceptance.** The test builds the explicit root/suffix selector set above, asserts that selectors containing `list.boxed-list` or `list.content` equal that set, asserts every corresponding parsed `self.rules` dictionary equals `{"border-radius": "0"}`, and compares each radius with both frame selectors. Include the first/last and checked/unchecked expander selectors in that assertion; a root-only reset is incomplete. Existing frame, card and standalone-sheet checks pass. Document declaration coverage rather than rendered-pixel evidence. Run `make check`. Keep implementation to the three named files and below a few hundred changed lines including tests; shortcut keycaps are not a prerequisite.
